# Task types

Pick exactly one. When two fit, pick the one the task's done criterion is about.

| Type | The criterion is about |
|---|---|
| bug-fix | wrong behaviour that now behaves right |
| feature | new behaviour someone asked for |
| refactor | the same behaviour with better structure |
| data-sql | queries, pipelines, schemas, data cleaning |
| ml-experiment | training, evaluating or comparing models |
| docs | text a person reads: README, docs, comments |
| code-review | judging someone else's change |
| ui | what a user sees and clicks |
| research | reading, comparing options, answering a question, with no code as output |
| ops-config | build, CI, deploy, environment, settings |
