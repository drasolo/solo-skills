# Open-source project

Maintainers plus outside contributors who come and go.

- **Lease:** 7d
- **Decision deadline:** 1 week after posting
- **Extra task fields:** Area, Good first task (yes/no)
- **Default grouping:** Area
- **Default stages:** implement, review
- **Who votes:** maintainers; contributors comment, maintainers vote
- **Extra kickoff questions:**
  - Which maintainers vote, and who is manager?
  - What may an outside contributor's agent claim without asking first?
  - Which decisions are public commitments (API, formats) that need a long deadline?
